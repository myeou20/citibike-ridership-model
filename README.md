# Citi Bike Ridership Model

This project builds a daily Citi Bike ridership dataset by combining Citi Bike trip data with NOAA weather observations using SQL in Google BigQuery.

## Repository Structure

- **code/** – Jupyter notebooks for exploratory data analysis (EDA), preprocessing, and modeling.
- **data/** – Exported datasets, including `citibike_weather_daily.csv`.
- **queries/** – SQL queries used to build the analysis dataset.
- **docs/** – Documentation, notes, and supporting materials.
